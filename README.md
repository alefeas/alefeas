🧑 [Portfolio](https://github.com/alefeas/portfolio): Sitio web donde centralizo mi experiencia, proyectos y datos de contacto. El objetivo es ofrecer una presentación clara y atractiva de mi perfil profesional. Tecnologías utilizadas: ReactJS/SCSS/MUI. [Link a la aplicación](https://portfolio-alejo-feas-matej.netlify.app/).

🎬 [Felix](https://github.com/alefeas/felix-movies): Aplicación web que permite explorar y buscar información sobre películas y series. Cuenta con funcionalidades como visualización de detalles y la posibilidad de agregar títulos a una lista de favoritos, almacenada en la nube con Firebase. La interfaz es totalmente responsive y ofrece una experiencia fluida para el usuario. Desarrollada sobre todo con ReactJS, Firebase (Cloud Storage) y SCSS. [Link a la aplicación](https://felix1.netlify.app/).

👚 [Panthera Clothes](https://github.com/alefeas/panthera-clothes): E-commerce de indumentaria para todos los géneros, que permite explorar productos a través de categorías y filtros de búsqueda (como tipo de prenda o género), agregar artículos al carrito y realizar compras de manera intuitiva. Tecnologías: HTML, JavaScript y SCSS. (Sin Responsive Web Design) [Link a la aplicación](https://alefeas.github.io/panthera-clothes/).
